The mining HUD reader.

- `sc-ohseearr-mining-hud`: reads the signature a ship's scan shows on its HUD (the plate above the heading tape), as a
  number with the box it was read in; no layout model, the stock detector and recognizer.
- No change to the engine, the models or the other readers.

## Use

Every crate by the tag, as before (README, "Use"); the new one:

```toml
sc-ohseearr-mining-hud = { git = "https://github.com/w00zla/sc-ohseearr", tag = "v0.2.0" }
```
