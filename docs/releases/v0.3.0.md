The Linux window capture.

- `sc-ohseearr-capture-linux`: the capture of one window on Linux through the ScreenCast portal (xdg-desktop-portal)
  and PipeWire. The user picks the window once, a restore token brings it back; frames with the mouse cursor's
  position, and a frame with the cursor at rest. Verified on KDE Plasma 6 (Wayland).
- `sc-ohseearr-capture`: the parts of a capture loop that are the same on every platform (`Pixels`, the change gate
  `Gate`, the cursor-rest detector `Rest`), moved out of `sc-ohseearr-capture-win`.
- No change to the engine, the models or the readers.

## Breaking

- `Pixels`, `Gate`, `Rest`, `REST`, `PULL_POLL` and `PULL_TIMEOUT_MS` come from `sc-ohseearr-capture`, no longer
  from `sc-ohseearr-capture-win`.
- `Rest::update()` is gone: pass `sc_ohseearr_capture_win::cursor_pos()` to `Rest::observe`.

## Use

Every crate by the tag, as before (README, "Use"); the new ones:

```toml
sc-ohseearr-capture = { git = "https://github.com/w00zla/sc-ohseearr", tag = "v0.3.0" }
sc-ohseearr-capture-linux = { git = "https://github.com/w00zla/sc-ohseearr", tag = "v0.3.0" }
```

Building on Linux needs libpipewire's headers (`libpipewire-0.3-dev`, `pipewire-devel`) and clang.
