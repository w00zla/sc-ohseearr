# 0003. English everywhere

- Status: accepted
- Date: 2026-11-05
- Scope: code, comments, docs, UI texts, commits

## Context
The repository is for other developers. The Quartermaster repo keeps its UI texts in German.

## Decision
English for everything in this repository: identifiers, comments, docs, UI texts (examples, tools), commit
messages. No German anywhere.

## Consequences
- Code moved over from the companion is English already; its German UI texts stay in the companion.
